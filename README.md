## Project Overview
Developed an interactive Spotify Streaming History Dashboard in Microsoft Power BI to analyze user listening behavior from 2013–2024. The dashboard provides insights into artist popularity, streaming patterns, music discovery trends, and user engagement across different time periods.
### Business Questions Answered by the Dashboard
Which artists received the highest listening time between 2013 and 2024?
What time of day do users stream music the most?
Which songs have the highest play duration?
How does music listening behavior vary across different years?
Which tracks are skipped the most and which are completed more often?
What is the ratio of new music discovery across different months?
Which months recorded the highest engagement with new music?
What trends can be identified in user streaming habits over time?
Which artists maintain consistent listener engagement across multiple years?
How do listening patterns differ between morning, afternoon, evening, and night?
